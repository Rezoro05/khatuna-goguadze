# Khatuna Goguadze — Executive Function Trainer

Static, deployable mirror of [khatuna-goguadze.rezoro.chatgpt.site](https://khatuna-goguadze.rezoro.chatgpt.site/).

## Preview locally

Run a static HTTP server from the repository root:

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## Structure

- `index.html` — home page
- `about/` — biography page
- `projects/` — projects listing and project detail pages
- `assets/` — compiled styles and scripts
- `images/` — site imagery
- `robots.txt` and `sitemap.xml` — search-engine metadata

This repository contains the deployable compiled website rather than its original editable source project.
